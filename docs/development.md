# Разработка и локальная сборка

Локальный плагин Figma Design: композиции из предоставленных SVG по названиям, ручному выбору или метафоре через OpenRouter. Каталог: 10 типов × S/L × главное/фоновое состояние = 40 вариантов. Новые предметы не генерируются.

## Установка и сборка

Для установки готового public или private demo пакета нужен только Figma Desktop — Node.js не требуется. Распакуйте соответствующий ZIP целиком и импортируйте лежащий рядом с code.js и ui.html manifest.json через Development → Import plugin from manifest. Public: release/public/plugin/manifest.json; private demo: release/demo/plugin/manifest.json. В готовых пакетах уже сохранён зарегистрированный ID: не удаляйте его.

Node.js 22+ нужен только для сборки из исходников по командам ниже. В PowerShell при блокировке npm.ps1 используйте npm.cmd.

В корневом `manifest.json` уже сохранён строковый `id`, выданный Figma владельцу проекта: `1703137590700223750`. Повторная регистрация для этой сборки не требуется. Если вы создаёте собственную регистрацию, в Figma Desktop выберите Plugins → Development → New plugin → Figma Design → Custom UI и сохраните шаблон в отдельной папке `figma-registration`. Перенесите **только поле `id` своей регистрации** из шаблонного manifest.json в корневой manifest.json проекта; исходники шаблона не заменяют Vector Composer. Затем выполняйте команды ниже. Не выдумывайте ID и не присваивайте чужую регистрацию. Сборщик останавливается до создания новой сборки, если ID отсутствует или имеет неверный формат.

```powershell
npm ci
npm run check
npm run build
node scripts/create-examples.mjs
node scripts/create-examples.mjs --check
npm run package
```

`npm test` запускает тесты; `check` проверяет синтаксис, тесты и public build. Сборка: `dist/public/`. Упаковка создаёт `release/public/plugin/manifest.json`, code.js и ui.html; архивы `release/public/Vector-Composer-public.zip` и `release/public/Vector-Composer-source.zip`. Исходники включают документацию, примеры и библиотеку без локальных секретов.

Распакуйте плагин целиком. В отдельном тестовом файле Figma Desktop: Plugins → Development → Import plugin from manifest → `release/public/plugin/manifest.json`, затем запустите Vector Composer через Development. Для разработки после build можно импортировать корневой manifest.json, указывающий на dist/public. Manifest переносится вместе с code.js и ui.html. Source, public и demo сохраняют один зарегистрированный ID. Он необходим для private pluginData и повторного открытия композиции. Ранний импорт книги без ID проверял только SVG-геометрию; сохранение и восстановление сцены этим не подтверждались.

## Работа

Введите «книга, телефон, наушники» в «По названиям» или выберите карточки «Из библиотеки». Неизвестный текст отображается явно. Укажите роль предмета, S/L, формат, раскладку и палитру; нажмите «Создать композицию». Редактируйте слои штатными средствами Figma. «+» и «Добавить выбранные» дополняют активную сцену. «Перекомпоновать» размещает текущие предметы без AI и меняет ручное расположение. «Применить S / L» меняет исходную версию; «Перекрасить» — цвета. Если новый предмет при текущем масштабе не помещается, добавление целиком отклоняется с понятной ошибкой, сохраняя текущую сцену и ручные правки. Выберите все нужные предметы и создайте новую композицию, чтобы рассчитать масштаб сразу для полного набора.

«Загрузить JSON» принимает examples/palette.json и автоматически перекрашивает активную сцену. Формат: id, name, background из трёх hex, objects из трёх hex, ink, paper. Выделите фрейм композиции или его дочерний слой, нажмите «Скачать SVG»: экспорт текущих узлов включает ручные изменения. После перезапуска выделите сохранённую композицию для продолжения работы.

В режиме «По метафоре · AI» по умолчанию используются цветные главные версии всех подобранных предметов. «Разрешить фоновые предметы» позволяет модели использовать монохромные исходники: их заливка может совпадать с фоном холста, что соответствует библиотеке. Для уже созданной сцены «Сделать все цветными» заменяет только фоновые предметы исходными главными версиями без нового AI-запроса. Положение, поворот, масштаб, порядок и видимость сохраняются; внутренние ручные изменения заменяемых фоновых предметов уступают исходной цветной версии. Уже главные предметы не заменяются. После повторного открытия восстанавливается также способ подбора AI/названия/библиотека.

## Ключ и модель

В «Подключение OpenRouter» локально введите личный API-ключ, ID модели и нажмите «Проверить подключение». Свой ключ хранится в памяти запуска. «Очистить ключ» удаляет его и выключает demo; встроенный ключ включается явно. Не передавайте ключ в чат. Начальный ID — `nvidia/nemotron-3.5-super-vl:free`: фиксированная бесплатная модель с JSON-ответом и отключённым reasoning. Оркестратор проверил этот профиль настоящим Node-запросом: HTTP 200, завершение stop и разрешённые предметы. Пользователь подтвердил AI в установленном private-пакете без ручного ввода своего ключа; реальные изображения результата — в docs/demo.md. Лимиты и доступность бесплатных моделей зависят от OpenRouter и провайдера.

`openrouter/free` оставлен экспериментальным маршрутом: выбор модели и видимый JSON нестабильны. Фиксированный NVIDIA default проверен реальным запросом. Произвольной пользовательской модели дополнительные параметры не навязываются. «По метафоре · AI» передаёт текст и метаданные каталога OpenRouter, без SVG. Платного fallback нет. Прямой выбор, палитры и экспорт работают без AI.

Для локальной приватной сборки:

```powershell
npm run configure:demo
npm run build:demo
npm run package:demo
```

configure:demo запрашивает ключ без эха и сохраняет .env.local с моделью NVIDIA. Demo: dist/demo/, устанавливаемый `release/demo/plugin/manifest.json`, архив `release/demo/Vector-Composer-demo.zip`. Пакет содержит встроенный ключ и должен храниться приватно. Приватный NVIDIA-пакет установлен и проверен пользователем без ручного ввода своего ключа. Native-цикл и фактический SVG также подтверждены: 293 path, без растра. Иллюстрированная демонстрация и границы проверки — в docs/demo.md и docs/verification.md. .env.local игнорируется git. Public и source ZIP без временного ключа; private demo содержит его и передаётся отдельно.

После демонстрации владелец вручную удаляет временный ключ в OpenRouter. AI с отозванным ключом перестанет работать; можно ввести свой. Созданные слои и локальные действия остаются доступны. Автоматического отзыва нет.
