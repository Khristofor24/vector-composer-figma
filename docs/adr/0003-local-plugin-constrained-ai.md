# ADR 0003 — Локальный плагин и ограниченный AI-подбор

## Контекст
Метафора требует смыслового подбора, а прямой выбор и повторное размещение должны работать независимо от доступности модели. Продукт задан как локальный плагин Figma Design без сервера.

## Решение
Разделяем интерфейс и работу с документом внутри обычного плагина, обмениваясь сообщениями с идентификаторами запросов. Направляем AI-запросы прямо в OpenRouter; модель получает текст и компактный каталог, возвращает только разрешённые предметы, роли и объяснение. Проверяем ответ, а размещение выполняем локально. Прямые названия и синонимы распознаём без сети; перекомпоновка не вызывает AI повторно.

## Почему
Отдельный сайт, сервер и сторонние API находятся вне рамок спецификации. Генерация SVG или координат моделью выходит за контракт подбора. Локальные эвристики и сохранённые примеры не заменяют настоящий AI-вызов и не выдаются за него. Платный fallback запрещён.

## Последствия
Недоступность модели не блокирует прямой выбор, палитры и экспорт. Ответ модели требует проверки структуры, ID и ролей даже при JSON-режиме. Сетевые ошибки обрабатываются явно; реальные запросы и доступ из Figma Desktop требуют отдельной проверки и не доказываются моками.
