# ADR 0008: Фиксированная бесплатная модель по умолчанию

## Контекст

При реальных запросах бесплатные Gemma31 и Gemma26 возвращали HTTP 429. Маршрут `openrouter/free` выбирал, в частности, reasoning-модель `dots-3-note-preview`: она потратила все 1200 выходных токенов на reasoning и завершилась с `finish_reason: length`, `content: null`. Даже JSON-mode не обеспечил видимого ответа при таком случайном выборе модели.

Проверенный запрос к `nvidia/nemotron-3.5-super-vl:free` с JSON-object, `require_parameters: true` и `reasoning.enabled: false` вернул HTTP 200, `stop`, 94 токена и допустимые ID/roles без reasoning. В официальном каталоге для этой модели указаны нулевые цены prompt/completion и `mandatory: false`. Пользователь подтвердил смену строки модели в локальной конфигурации.

## Решение

Закрепить `nvidia/nemotron-3.5-super-vl:free` как согласованный default в исходниках, сборщике, helper, примере конфигурации и UI. Для неё использовать проверенный JSON-профиль с отключённым reasoning. Исходная Gemma31 остаётся доступной при ручном выборе с прежним поддерживаемым JSON-профилем; неизвестным custom-моделям параметры принудительно не навязывать.

Не выбирать платные модели и не вводить автоматический paid fallback. Строгая проверка структуры ответа, разрешённых ID и ролей остаётся без изменений. Публичный идентификатор модели допустим в исходниках; значение ключа не является частью этого решения и не попадает в публичную конфигурацию или сборку.

## Почему

Сохранение Gemma в качестве default оставляло воспроизведённый HTTP 429 на основном демонстрационном пути. Случайный бесплатный роутер не устранил проблему: проверенный маршрут исчерпал лимит на reasoning без JSON-ответа. Закреплённая NVIDIA дала содержательный валидный ответ в проверенном профиле, поэтому её выбор опирается на выполненный запрос, а не на предположение о доступности бесплатного маршрута.

Это изменение стратегии default для проверки AI, а не снятие требования настоящей AI-интеграции или ослабление валидатора.

## Последствия

Все места задания default должны оставаться согласованными. Пользователь сохраняет возможность вручную выбрать другую модель. Бесплатные квоты, HTTP 429 и доступность провайдера остаются ограничениями; успешный прототип не гарантирует постоянную доступность модели.

HTTP 200 прототипа подтверждает только выполненный запрос и его ответ. Полная приёмка приватного устанавливаемого пакета в настоящем Figma Desktop, включая native-сценарий, ещё ожидается; считать её PASS на основании этого запроса нельзя.
