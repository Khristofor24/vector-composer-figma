# ADR 0006 — Единый масштаб и явные границы компоновки

## Контекст
Композиции используют три формата и три раскладки, сохраняя относительные размеры предметов, тени и место под заголовок. Добавление должно учитывать уже существующий фрейм.

## Решение
Вычисляем детерминированную раскладку из канонических размеров с единым масштабом предметов выбранной исходной версии. Учитываем тени и безопасные границы; для варианта «Под заголовок» сохраняем свободную левую область. При добавлении используем сохранённый масштаб и фактические границы импортированных узлов. Если предметы не помещаются, отказываем в добавлении атомарно.

## Почему
Независимое растягивание предметов под ячейки нарушает исходные соотношения размеров. Выход за границы вместо отказа противоречит требованиям компоновки. Изменение существующих трансформаций и цветов ради добавления нарушает сохранность текущей сцены.

## Последствия
Перекрытия допустимы только при сохранении узнаваемости. Некоторые добавления физически невозможны при прежнем масштабе и завершаются понятной ошибкой без частичных изменений; это не основание скрыто уменьшать существующие предметы.
