# Реально использованные инструменты

- Codex и Autopilot: требования, спецификация, код, тесты и документация.
- Codex agents: исполнение отдельных тасков и независимые проверки сборки.
- Figma MCP: отдельные реальные проверки векторной книги и SVG roundtrip; не генератор предметов.
- Firefox DevTools MCP: браузерный QA собранного UI с mock Figma parent; не AI-генератор и не Figma Desktop.
- OpenRouter: реализованный провайдер подбора разрешённых ID по метафоре; фиксированный default nvidia/nemotron-3.5-super-vl:free реально использован в production Node-вызовах и установленном private UI. Пользователь показал AI-композицию без ручного ввода собственного ключа; это не сохранённый mock.

Предметы происходят из предоставленных SVG; генератор изображений для них не применялся. Примеры — локальная компоновка, не ответы модели. Версии моделей Codex не заявляются без подтверждённого runtime evidence.
